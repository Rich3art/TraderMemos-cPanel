# TraderMemos cPanel Deployment

This repository builds a cPanel-friendly TraderMemos artifact from upstream:

https://github.com/sinhong2011/TraderMemos

It packages:

- `web/dist` static SPA
- Linux x64 Go API binary
- Linux x64 TraderMemos admin CLI
- Node.js Passenger launcher for cPanel

The live domain target is:

https://journal.ranksmedia.com
